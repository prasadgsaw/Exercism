# Triangle Classification

## Overview
This Python exercise classifies a triangle based on the lengths of its three sides.

## Functions

- `equilateral(sides)`: Returns `True` if all three sides are equal and form a valid triangle.
- `isosceles(sides)`: Returns `True` if at least two sides are equal and the sides form a valid triangle.
- `scalene(sides)`: Returns `True` if all three sides are different and the sides form a valid triangle.

## Validation Rules

- All side lengths must be greater than zero.
- The sum of any two sides must be greater than the third side.
- Invalid triangles must not be classified as equilateral, isosceles, or scalene.
